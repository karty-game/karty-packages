# Preview source

`controller.jpg` is an unchanged copy of the existing Crate Room sample
preview from `karty-game/karty`, `samples/crate-room/preview.jpg`.

[Sample source](https://github.com/karty-game/karty/tree/main/samples/crate-room)

This is an actual Karty sample capture, used to show the corresponding view
style. It does not bundle the sample's artwork, gameplay or UI into this code
package. The image is covered by the repository's MIT license; see
[LICENSE.md](../LICENSE.md). No generated illustration is used.

Crate Room uses the SDK built-in first-person component. This portable package
provides calculations for custom integrations with the same view style.
