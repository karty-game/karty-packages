# Karty Packages

Reusable code and assets for Karty games, released as portable `.kpkg` archives.

[Browse packages](https://karty-game.github.io/karty-packages/) · [Contributing](CONTRIBUTING.md)

## Local development

```sh
mise install
mise run check
mise run package -- fps-kit
```

Archives and checksums are written to `dist/releases/`.
See [Contributing](CONTRIBUTING.md) for releases, the catalog and website previews.
